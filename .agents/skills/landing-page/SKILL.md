# Landing Page Strategy

Use quando criar ou reestruturar landing pages.

Antes de escrever código, defina:

- objetivo;
- público;
- proposta;
- CTA;
- narrativa;
- seções.

Estrutura padrão:

1. Hero
2. Problema
3. Proposta
4. Como funciona
5. Benefícios
6. Funcionalidades
7. Demonstração
8. Diferenciais
9. Planos/modelos
10. Prova
11. FAQ
12. CTA final

A estrutura pode ser alterada se houver justificativa estratégica.

Nunca adicionar uma seção apenas porque "landing pages normalmente têm".
