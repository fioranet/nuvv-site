# Website Audit

Use esta skill quando o usuário solicitar análise de uma página, landing page,
screenshot, site ou experiência digital.

## Processo

1. Entender o objetivo da página.
2. Identificar o público.
3. Identificar o produto.
4. Analisar o hero.
5. Analisar a narrativa completa.
6. Analisar cada seção.
7. Avaliar proposta de valor.
8. Avaliar copy.
9. Avaliar UX/UI.
10. Avaliar CTAs.
11. Avaliar conversão.
12. Identificar objeções.
13. Identificar ausência de prova.
14. Identificar redundâncias.
15. Identificar oportunidades.

## Regra

Não começar sugerindo mudanças visuais.

Primeiro identificar problemas estratégicos.

Depois UX.

Depois copy.

Depois visual.

## Resultado

Entregar:

- diagnóstico;
- pontos fortes;
- problemas;
- prioridades;
- recomendações;
- estrutura sugerida;
- copy apenas quando solicitada.
