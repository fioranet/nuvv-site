# NUVV — PRODUTOS

## NUVV GUARD

### Categoria
Segurança inteligente para condomínios.

### Público
- Síndicos
- Condomínios
- Administradoras
- Moradores

### Problema
Condomínios precisam integrar segurança, monitoramento, acesso e experiência do morador.

### Proposta
Uma experiência integrada de segurança condominial.

### Componentes possíveis
- CFTV
- Controle de acesso
- Visitantes
- Aplicativo
- QR Code
- Tags
- Comunicação
- Recursos inteligentes

### Posicionamento
Não é apenas um sistema de câmeras.

É uma solução de segurança e experiência para condomínios.

# POSTE DE MONITORAMENTO INTELIGENTE NUVV

### Categoria
Infraestrutura de monitoramento inteligente.

### Público
- Condomínios
- Moradores
- Ruas
- Comunidades
- Comércio
- Áreas de circulação
- Parceiros
- Projetos públicos/privados

### Aplicações
- Frente de condomínios
- Áreas internas de condomínios
- Ruas abertas
- Vilas
- Corredores comerciais
- Praças
- Áreas de grande circulação

### Conceito
O poste não deve ser vendido simplesmente como hardware.

É uma infraestrutura que pode combinar:

- câmeras;
- conectividade;
- monitoramento;
- inteligência;
- serviços digitais;
- eventualmente Wi-Fi;
- eventualmente mídia/parcerias.

### Modelos possíveis

- contratação;
- rateio;
- parceria;
- patrocínio;
- investimento compartilhado.

# CFTV CLOUD

### Categoria
Monitoramento profissional em nuvem.

### Objetivo
Permitir gerenciamento e acesso remoto às câmeras.

### Posicionamento
Infraestrutura profissional de monitoramento, não apenas armazenamento de vídeo.
