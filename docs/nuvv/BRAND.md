# NUVV — BRAND GUIDELINES

## Personalidade

A Nuvv deve parecer:

- moderna;
- tecnológica;
- segura;
- confiável;
- simples;
- humana;
- premium sem ser elitista.

## Evitar

- excesso de linguagem corporativa;
- excesso de termos técnicos;
- exageros;
- promessas absolutas;
- comunicação genérica;
- "revolucionário";
- "inovador" sem prova;
- "solução completa" sem explicar.

## Visual

A identidade utiliza principalmente:

- azul;
- verde;
- grafite;
- branco;
- gradientes tecnológicos.

## Comunicação

Preferir:

"Veja quem está chegando."

em vez de:

"Tenha acesso a uma solução avançada de controle de acesso."

Preferir:

"Mais controle para o condomínio."

em vez de:

"Uma plataforma integrada de gestão condominial."

A tecnologia deve aparecer como meio para produzir um benefício.
